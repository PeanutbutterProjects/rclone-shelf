rclone shelf

A private, single-user file copy setup.

What it is

rclone shelf is one person's own setup of rclone, the open-source file copying tool. It runs on its owner's computer and checks every 10 minutes while the computer is awake. It copies selected work files from that computer to one folder in the owner's Google Drive, so the owner can read them on a phone. A copy can wait while the computer sleeps, while a run is still busy, or while the connection fails.

The owner can leave a written request note in that folder. The setup reads those notes and copies a requested edit back to the computer. Some files are never overwritten this way; their edits are set aside for review.

Who can use it

It is intended only for its owner's personal use and is not offered as a service to others. There is nothing to sign up for or download here.

Google data

It uses Google Drive access to list, read, upload, update and move files in that one folder, and to move a file there to the Drive trash when the owner's written request names it. The setup itself does not permanently delete the owner's files. Details: privacy policy.
