Privacy policy

rclone shelf · last updated 5 November 2026

Who this covers

rclone shelf is intended only for its owner's personal use, with the owner's Google account. It is not offered as a service to others.

This policy covers the copy setup. These information pages are hosted by GitHub Pages, which keeps its own visitor logs.

What Google data it can reach

When the owner signs in, Google grants the app permission to view and manage files throughout the owner's Drive. The copy tool on the owner's computer is set to use one folder and its subfolders. That limit is a setting on the owner's computer; it does not narrow the permission Google grants.

How the data is used

  • To list the files in that folder, with their names, sizes and checksums, so changes can be noticed.
  • To upload and update selected work files from the owner's computer.
  • To read the owner's request notes, and to copy an edit back to the computer when a request asks for it.
  • To move processed notes and edits within the folder, and to keep earlier versions that the request process needs.
  • To move a file in that folder to the Drive trash, only when the owner's written request names it. The setup itself does not permanently delete the owner's files.

The setup also writes status reports and receipts into that folder, keeps run logs on the owner's computer, and creates alerts in the owner's Reminders app, including error details when a run fails. It has no advertising or analytics.

Where the data is kept

Work files and the setup's records are kept on the owner's computer and in the owner's Google Drive; alerts are kept in the owner's Reminders. The Google sign-in pass is kept in a settings file on the owner's computer, outside the copied folder. Computer backups and Reminders syncing follow the owner's own device settings.

Sharing

Files travel only between the owner's computer and the owner's Google Drive, and sign-in information is exchanged with Google to allow that. Alerts go to the owner's Reminders, which may sync to the owner's other devices. The setup does not sell data or share it beyond the services described here. Other apps the owner uses to read or edit the shelf files handle data under their own policies.

Keeping and removing data

Work files, saved versions, request notes, receipts and logs stay until the owner removes them. A file moved to the Drive trash is deleted permanently by Google after 30 days, or sooner if the owner empties the trash. The app's access can be ended at any time at myaccount.google.com/permissions; that stops future access but does not remove copies already kept on the computer, in Drive or in Reminders.

Changes

If the setup changes what it does, this page is updated and its date changes.
